# Tame Impala Fan Website

A psychedelic, responsive fan-made Tame Impala website built with vanilla HTML, CSS and JavaScript.

## Run locally

Open `index.html` in your browser.

## GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/root`.
6. Save.

Your site will be available at the GitHub Pages URL GitHub provides.
